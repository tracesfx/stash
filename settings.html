Settings

Theme
Applies to the gallery, settings, popup and radial wheel. Liquid Glass blurs the desktop behind the windows.
Liquid Glass colours
The gradient behind the gallery, settings, popup and radial wheel.
Capture shortcut
Tap to snip a region. Hold for the radial wheel. Needs a modifier (Ctrl, Alt, Shift or Win).
Wheel hold delay
How long to hold before the wheel opens.
ms
Library folder
A OneDrive or Dropbox folder keeps it synced. Changing this only affects new captures; move existing files yourself to keep them in the gallery.
Start with Windows
Runs quietly in the tray at sign-in.
Confirmation popup
A small preview after each capture, with click-to-caption. Captions can still be added in the gallery.
Record page URL from browsers
Reads the address bar through Windows UI Automation. Chromium browsers turn on their accessibility mode when asked, which can slow page loads a little.
